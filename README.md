# Dashboard-de-Vendas-do-Xbox-com-Excel

Sobre o projeto

O objetivo foi transformar os dados disponíveis em uma apresentação visual clara e objetiva, aplicando boas práticas de construção de Dashboards e visualização de dados.
O projeto conta com:
  -Tabela dinâmica para organização e análise dos dados;
  
  -Gráficos para apresentação dos principais resultados;
  
  -Indicadores de vendas de serviços;
  
  -Filtros por período de assinatura;
  
  -Menu lateral para facilitar a navegação;
  
  -Organização de cores, formas, alinhamentos e hierarquia visual.
  

Ferramentas:
-Microsoft Excel (Tabelas Dinâmicas, gráficos, segmentação de Dados,formatação e visualização de dados)

Resultado:
O projeto demonstra a aplicação prática de conceitos de análise e visualização de dados, com foco na construção de um Dashboard funcional, organizado e visualmente consistente.
